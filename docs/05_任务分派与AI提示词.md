2. **评级按总失败次数**（这是抑制"故意送死刷 buff"的唯一锁扣）。

## 5. 各人的注意事项（都是踩过的坑）

### 所有人

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | AI 会顺手重构整个项目 | 提示词里的"文件边界"约束**每次开新对话都要重新贴** |
| 2 | Godot C# 里**被销毁的节点不等于 `null`** | 判空一律 `GodotObject.IsInstanceValid(node)` |
| 3 | 移动放 `_Process` 会随帧率变速 | 移动/碰撞 → `_PhysicsProcess`；UI/动画 → `_Process` |
| 4 | `ProcessMode` 设错界面会冻住 | `WhenPaused` = **只在暂停时跑**。`Hud` 已设 `Always`（要边打边刷新）；`UpgradePicker` 用 `WhenPaused`（只在暂停时用）。照抄现有写法 |
| 5 | 关掉 Godot 的 C# 热重载 | 编辑器 → .NET → 取消「自动重载项目」。统一 **VS Code `Ctrl+Shift+B` 编译 → 回 Godot → F5** |
| 6 | 提交前 | `git status` 只看自己的文件 → 编译通过 → 跑一遍没崩 → **pitch 一遍再提交**（全员都在 `main`，不开分支） |

### P1 · 守门人

- 你是 `.tscn` 唯一创建者，别人要场景/节点就 @ 你。**创建后把节点路径告诉对方**。
- ⚠️ **三选一必须有回应者**。你没做完 P1-1 时，`AutoUpgradeFallback` 会自动跳过选择——这是正常的，不是 bug。你的 `upgrade_picker.tscn` 一出现，它就自动下岗。
- 三选一时 `GetTree().Paused = true`，**弹窗根节点必须 `ProcessMode = WhenPaused`（或 `Always`）**，否则界面自己也会卡住点不动。
- UI 布局用容器（`VBoxContainer` / `HBoxContainer` / `CenterContainer`），别用绝对坐标。
- 所有显示文案走 `GameManager.I.T("key")`，**不许硬编码**（换皮全靠它）。

### P2 · 战斗手

- ⚠️ **`Velocity` 只允许在 `EnemyBase._PhysicsProcess` 那三行里写**：① 合成 → ② 反射 → ③ `MoveAndSlide`。加任何速度类效果都塞进 `ComposeVelocity()`，不要在别处写 `Velocity`。多处写是本项目最容易出的 bug。
- ⚠️ 反射的**方向判断不能省**（`if (p.X <= min.X && v.X < 0f)`）。省了敌人会贴着边界反复取反，剧烈抖动。
- ⚠️ **不要给敌人水平速度分量设下限**（`|vx| ≥ 速度×0.35` 之类）。这个方案已被否决，别加回来。
- ⚠️ 敌人是**对象池复用**的。`Configure()` 里已经清了无敌帧和反弹计数——你加新字段时**记得在 `Configure()` 里重置**，否则新刷出来的敌人会带着上一条命的残留状态（表现为"打不死"）。
- ⚠️ 玩家碰撞用的是 **Area2D 受伤盒 + 每帧 `GetOverlappingBodies()`**，不要改回 `GetSlideCollisionCount()`。玩家静止时自己的 `MoveAndSlide` 速度为 0，检测不到撞上来的敌人，会**漏伤害**。
- 所有伤害必须走 `DamageSystem.Deal(ref HitInfo)`，不要直接改血量字段。
- 无敌帧、穿透这类效果实现为 `IModifier` 或 `HitInfo.Canceled`，**不要写进 `DamageSystem` 主体**。
- 追踪怪的血量/速度**恒定，免疫敌人线所有强化**——读 `EnemyStat.TrackerHP` / `TrackerSpeed`，不要读 `HP` / `MoveSpeed`。

### P0 · 你（策划 · 逻辑手）

- 你几乎不用打开 Godot 编辑器。词条 `.tres` 是**纯文本文件**，可以在 VS Code 里直接写（模板见 `ai_prompts/P0_策划逻辑手.md`）。
- ⚠️ 词条是**平铺池，不是解锁树**：数据类里**不要**加 `Prerequisite` 字段，抽取器**不要**写解锁逻辑。"链"只是你的设计辅助，不进游戏。
- ⚠️ **吸血悬崖**：`每次撞击净耗 = 1 − Y/X`。`Y/X ≥ 1` 时无限续航、游戏崩坏 → **必须 `X ≥ 2` 且 `Y < X`**。
- ⚠️ **加速反弹**已带衰减（第 n 次增量 = `AccelBase × AccelDecay^(n-1)`，硬顶 `AccelCap`）。三参数独立可调，别改成固定增量。
- 改 `data/**` 里的数值**不用改代码、不用重新编译**，F5 直接看效果。
- 权重和稀有度**等你词条设计完再定**，别现在拍脑袋。

### A1 · 美术 / 音频

- ⚠️ **音频文件名一字都不能改**：`shoot` `hit` `enemy_die` `player_hurt` `upgrade` `win` `lose` `bgm`（`.wav` 或 `.ogg`）。文件放 `res://audio/` 就会被自动加载，代码零改动。
- 素材尺寸：玩家/敌人/子弹按 1280×720 下单屏的实际观感定；**先出占位色块跑通流程，再替换精美素材**。
- 所有面向玩家的文字交给 P0 录进 `strings.tres`，**不要写死在素材上**（否则换皮要重画）。
